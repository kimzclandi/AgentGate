## 保留的问题与风险

- 工具数据与场景规模小；固定模型任务集不能代表开放任务正确率。
- 对话最终保存与运行终态不在一个事务中；崩溃后可能有已完成写入但缺少最终回答，必须查询审批记录。
- 取消/撤销会阻止后续工具执行，不能撤回已提交写入，也不能保证模型服务立即停止计算。
- 限额主要是全局限额，尚无租户公平调度或长期存储配额。
- HTTP errors 指标目前只计业务分发阶段错误，未覆盖全部认证/入口拒绝；不是完整请求错误率。已有性能结果为历史小数据集测试。
- OIDC/付费远端模型未经真实服务集成；UI 状态测试使用 DOM/fetch 替身，不是跨浏览器完整操作回归。
- 仓库简介与 topics 当前为空，尚无版本 release；README 已作为完整入口。GitHub Contributors 当前仅显示 kimzclandi，双人署名与提交贡献统计是不同信息，后续应通过真实贡献记录说明协作，不补造提交历史。
- 项目尚未选择代码许可证；没有擅自替两位共同作者确定授权条款。作者署名不代表已经核实个人贡献比例。
