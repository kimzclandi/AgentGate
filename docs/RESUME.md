# 简历描述（据实使用）

**AgentGate｜多租户 Agent 安全执行平台｜两人合作项目｜Go、SQLite、JWT/OIDC**

- 合作构建 Go Agent 安全控制面，将文档读取与工单更新接入统一资源授权入口，实现用户/Agent/运行权限交集、资源级租户隔离与无授权缓存的撤销。
- 实现参数绑定人工审批与持久幂等键，用本地数据库事务处理权限复查、审批消耗、业务写入和审计；20 路并发确认测试验证一次成功写入。
- 提供真实后端管理控制台与固定 HTTP 演示，覆盖跨租户拒绝、审批重放、撤销、超时、取消和重启；使用 Go race、vet 与 govulncheck 验证。具体结果以 TEST_REPORT 为准。
