# 面试讲解与追问

## 两分钟版本

我们合作做了 AgentGate，一个 Go 编写的多租户 Agent 安全执行样例。重点不是让模型更聪明，而是让工具执行具备可信身份、最小权限、审批和可验证结果。

用户认证后，服务端把用户映射到租户。创建运行的权限只能是用户、Agent 和请求范围的交集。文档读与工单写使用相同工具入口，每次重新检查资源所有者、租户和运行状态。高风险工单更新先持久化参数预览，人工确认时再次验权，在同一个 SQLite 事务内写业务数据、消耗审批并记审计，解决本地并发重放和撤销竞态。

我们用自动 HTTP 演示、单元/集成测试、race 和依赖扫描验证这些边界，也有真正连接后端的管理控制台。当前默认 mock，可选真实模型适配未拿凭证实测；不把本地事务说成分布式 exactly-once，不把内置工具运行说成容器沙箱。双方具体分工应按真实提交补充。

## 十分钟路线

- 0–1 分钟：问题与两种业务资源，展示控制台。
- 1–3 分钟：`auth.go` → `CreateRun` → `authorize`，身份与委托不由模型决定。
- 3–5 分钟：`Propose`/`Confirm`，参数规范化、幂等键与同事务复查。
- 5–6 分钟：撤销提交语义、超时与重启，展示失败用例。
- 6–7 分钟：模型仅产生结构化调用，文档文本不改变控制流；网络限制边界。
- 7–8 分钟：测试证据与分口径性能，说明 benchmark 不是公网 SLA。
- 8–9 分钟：单体/SQLite 的取舍，何时需要 Postgres、outbox 与 worker。
- 9–10 分钟：OIDC/服务身份/真实模型未完成验证的边界，以及个人实际贡献。

## 24 个追问

1. **为什么不用微服务？** 当前本地业务与审批可以在一个事务中完成，单体更容易审查一致性；执行不可信代码时才需要隔离进程。
2. **认证和授权有什么区别？** Verify 确认 subject；authorize 决定该用户委托 Agent 对具体资源做什么。
3. **tenant_id 为什么不能来自 body？** 用户可任意修改。tenant 由经过认证的 subject 查询 principals 获得；未知字段直接拒绝。
4. **Agent ID 能当用户身份吗？** 不能。Agent 是执行逻辑身份，运行还必须包含原发起用户和租户。
5. **如何限制委托？** CreateRun 验证请求 scopes 是用户角色与 Agent 允许动作的子集；执行时重查这些约束。
6. **再次委托如何处理？** 本版不提供该接口，不将 run ID 当 bearer token。未来需要 parent scope/expiry/tenant 单调收缩与父链撤销。
7. **为什么不是只在任务开始时授权？** 运行期间资源、身份或策略会变化；每次 Propose/Confirm 都加载实时属性。
8. **审批摘要涵盖什么？** 固定序列的 tenant、user、run、tool、规范化 params，SHA-256；审批凭证仍是用户认证，不是摘要本身。
9. **JSON 键顺序怎么处理？** 严格解码到固定 Go Params，再 Marshal，未知字段拒绝；不是直接哈希任意原始 JSON 字节。
10. **20 个并发确认会怎样？** 单连接串行事务中只有 pending 能更新，首个成功后其余收到 replay；测试检查资源 version 只加一。
11. **业务键重用但参数变了？** 唯一键查到已有提案，摘要不一致返回 idempotency_conflict。
12. **能保证 exactly-once 吗？** 仅本地 DB 事务内的一次成功状态迁移；网络响应丢失仍需查状态，远端副作用没有该保证。
13. **撤销与确认同时发生？** DB 串行化。确认先提交则副作用已完成；撤销先提交则确认拒绝，不能把过去的写入撤回。
14. **授权缓存如何失效？** 本版没有缓存。若引入缓存，需策略/身份版本和硬失效路径，明确最大撤销延迟。
15. **数据库不可用怎么办？** 受保护操作失败关闭；不会为了可用性跳过授权。审计不能落库时也不能伪称成功。
16. **模型幻觉工具名怎么办？** 注册表查不到就拒绝；工具参数严格验证，模型没有数据库或审批接口。
17. **是否完全防住提示注入？** 不声称。测试证明选定恶意文档不会改变程序授权/审批状态，不能证明所有自然语言攻击无效。
18. **怎么防 SSRF？** 无任意 URL 工具；模型客户端固定 HTTPS 主机，禁重定向/代理，解析并校验 IP 后再拨号。
19. **工作目录是不是安全沙箱？** 不是。只运行受信任内置代码，不执行模型代码；不防宿主攻击。
20. **重启后旧任务怎么处理？** running 变 interrupted，保留审批用于审计但旧运行无法执行，清理残余目录。
21. **如何理解性能结果？** 纯 Evaluate、鉴权 HTTP handler+DB、完整 mock Agent 本地运行是三个口径；不能拿纯函数时间替代业务延迟。
22. **为什么依赖扫描必须判断可达性？** 扫描可区分被调用漏洞与仅模块存在的漏洞；报告保留未调用条目，不声称依赖库全部无漏洞。
23. **OIDC 能否直接上线？** 目前只是 discovery/JWKS/client-ID 验证适配，缺真实 IdP 验证、登录会话、服务身份、TLS、运营与完整 token profile。
24. **你自己做了什么？** 依据真实分工回答；README 署名不等于个人实现了所有模块。明确 AI 辅助与开源复用，不编造工作量。
