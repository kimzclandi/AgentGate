# 项目状态

AgentGate 是由 kimzclandi 与 Lu-Ricardo-Y 共同制作的单实例 Go Agent 安全执行参考实现。当前支持 macOS/arm64 与 Linux；内置工具在 Go 进程内运行，不依赖 Docker。

## 已实现并验证

- 用户 / Agent / 租户 / 运行分离，JWT 验证、可信租户映射及资源 owner 授权。
- 三个 SQLite 业务工具：文档读取、工单读取、工单更新。
- 持久提案、参数绑定、人工确认、幂等与重放保护；第八步审批可完成，第九步提案拒绝。
- Ollama 自然语言、多工具调用、审批暂停和恢复、对话持久化。
- 撤销、取消、超时、重启中断和目录清理。
- 管理控制台、跨账号状态清理、过期/取消审批展示。
- 31 个 Go 顶层测试、2 个控制台状态测试；验证入口和结果见 [TEST_REPORT.md](TEST_REPORT.md)。

## 有适配但未经外部集成验证

- OIDC discovery/JWKS：尚缺真实 IdP 登录验证与 Web 登录流程。
- 远端 Chat Completions 兼容入口：有协议/网络/失败测试，未向付费提供商执行 E2E；目前单步规划。

## 后续优先级

1. 扩充业务数据与多轮任务质量评测，记录工具选择、回答正确率及失败分布。
2. 生产身份入口、服务身份、租户配额、备份恢复与审计保留。
3. 扩充失败诊断和业务指标；最终回答、运行成功与成功审计已在同一事务中提交。
4. 有明确业务需要后再增加外部连接器、写入对账及多实例架构。

尚无向量 RAG、任意代码沙箱、多 Agent 协作、策略编辑 API、WORM 审计或公网在线服务。项目代码许可证尚待共同作者决定。
