# Runtime 管控与边界

当前运行的是内置 Go 工具，不执行模型生成 shell/Python/二进制代码。因此本版不引入容器 worker，也不把 Go 进程称为安全沙箱。

| 限制 | 实现 |
|---|---|
| 活跃运行 | 全局最多 16，超额拒绝；最长 300 秒 |
| API 并发 | 32 个 slot，超额 429，应用不维护排队 goroutine |
| 运行步骤 | 最多 8 次提案/读取；达到上限后执行拒绝，审批也复查预算 |
| HTTP | 16 KiB body / header，普通 API 5 秒；chat/resume 245 秒 handler context，读写与空闲 timeout |
| 工具 | 每次 1 秒 context，取消传到 SQLite |
| 输出 | 工单写 4096 字节，读取和模型输出最大 16 KiB |
| 目录 | 每次运行随机 128 位 ID，目录 0700；终态清理，重启回收 |
| 重启 | 旧 running → interrupted，不能恢复为成功；旧审批保留可查但无法执行 |

无文件读取工具、任意 URL 工具、子进程或动态插件。resource_id 只能是 1–100 字符的字母数字、下划线和短横线；用户路径和符号链接不是受支持资源，不会传给 os.Open。工作目录路径仅由服务端 root 与随机 ID 生成。清理只接受 32 位十六进制运行 ID。数据目录和代码目录属于受信任宿主，宿主用户/管理员不在沙箱保护范围内。

默认工具无网络能力。可选模型客户端用固定部署配置的 HTTPS 主机、443 端口，禁用环境代理和重定向。DialContext 解析全部地址，拒绝私网、loopback、链路本地、共享地址及选定特殊地址段，再拨号已校验 IP，保留 TLS 主机校验。模型/API 参数不能选择网络目标。该机制是该客户端的实际网络出口限制，不是宿主进程级防火墙；新增网络代码必须复用或重新审计网络边界。

## 取消与清理

单次读任务成功即终结；单次写任务审批提交后自动终结。通用运行在取消、期限到达、撤销或重启时终止。数据库工具无独立子进程，故没有伪造进程终止测试。模型请求使用 HTTP context，客户端超时/取消关闭等待；不声称远端提供商停止了工作。

进程 SIGTERM/SIGINT 触发 5 秒 HTTP graceful shutdown，停止 sweeper，关闭 DB。数据目录 flock 防止第二个服务误做恢复。启动恢复和定时 sweeper 清理残余目录；失败时记录非敏感错误并重试。未做独立清理成功率指标。

## 外部结果未知

当前外部调用仅模型规划，不进行远端业务写入。连接失败/超时标记 model_result_unknown，自动重试次数为 0，HTTP 不暴露密钥/提供商响应正文。后续可人工重试，但不能保证提供商未计费。

引入远端写连接器前必须新增：持久 outbox、向供应商传播幂等键、unknown 状态、状态查询与对账任务、有限退避和人工处理。供应商不支持幂等/查询时不能宣称 exactly-once。本版本对此明确未实现，而不是用本地 SQLite 测试替代。

## 若以后支持任意代码

必须隔离 worker，非 root、只读基础 FS、受控 tmpfs、CPU/内存/PID 限额、默认无网络、禁宿主敏感挂载及 Docker socket，且验证容器退出和回收。本轮未实施此能力；当前环境 Docker socket 不可访问，也未声称完成容器测试。

## 本地模型运行边界

Ollama 适配器固定连接 127.0.0.1:11434，禁用代理、重定向和任意地址输入，不改变远端客户端的 SSRF 防护。Ollama 是受信任宿主服务，由操作者使用 OLLAMA_NO_CLOUD=1 启动；AgentGate 不管理其进程，也不能防止宿主操作者自行建立指向云服务的别名。

本地对话并发 2，超额直接拒绝；模型 HTTP 等待 90 秒，驱动 240 秒，最多 9 轮，输入上下文 64 KiB、响应 32 KiB。约每 200ms 查询运行/身份状态，撤销或取消会取消正在等待的模型请求。不能据此承诺底层推理进程已停止运算。

本地多步写入经审批提交后，运行保持活跃供模型继续读取结果；最后回答时结束运行。业务写入和审批在同一 SQLite 事务中，对话记录与最终运行状态不是同一事务；崩溃可能保留已成功写入但没有最终回答，应查询审批记录确认，不能自动重放写入。
