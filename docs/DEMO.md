# 使用指南

## 启动与连接

执行 `make run`，另开终端运行 `AGENTGATE_DEV=1 ./bin/agentgate -token alice`。打开 `http://127.0.0.1:8080`，粘贴令牌并连接。

## 文档与工单

- `read-doc doc-1`：读取当前租户下属于当前用户的文档。
- `read-ticket ticket-1`：查询工单内容。
- `update-ticket ticket-1 Resolved`：生成更新提案。核对待审批列表中的参数和摘要，确认后执行。
- 更新后再次读取工单，查看实际保存的内容。

## 运行与权限

控制台可以取消活跃运行、查看审计记录和撤销当前身份。撤销会阻止后续受保护操作；恢复本地用户的方法见 [API 文档](API.md)。恢复身份不会重新激活旧运行。

跨租户资源不可访问。例如 alice 请求 `read-doc doc-2` 会被拒绝。审批只能由原发起人确认，重复确认返回 approval_replayed。运行超时、被取消或在服务重启时中断后，旧审批无法执行。

## 自动流程验证

`make demo` 构建二进制，在临时目录启动独立服务，验证读取、审批写入、参数替换与重放拒绝、租户隔离、撤销、超时、取消和重启行为。脚本结束时回收自己启动的进程与临时目录，不修改正常 data 目录。

未配置模型时使用固定命令测试模式。自然语言、多步调用和审批后回答见[本地模型指南](LOCAL_MODEL.md)；可选远端入口见 [API 文档](API.md)。
